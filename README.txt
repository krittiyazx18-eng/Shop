NEXPLAY — Game Store (Demo)

วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ NEXPLAY ด้วย VS Code
3. เปิด index.html ผ่าน Live Server หรือดับเบิลคลิกเพื่อเปิดในเบราว์เซอร์

ฟังก์ชันที่มี
- ค้นหาเกม / กรองหมวดหมู่ / เรียงราคา
- ภาพปกเกมจาก Steam CDN (ต้องใช้อินเทอร์เน็ต) และภาพ SVG สำรอง
- รายการเกมที่อยากได้ และตะกร้าสินค้า
- ฟอร์มล็อกอินจำลอง
- หน้าชำระเงินจำลอง เลือก PromptPay หรือบัตรเครดิต และแสดงหน้าสำเร็จ

ข้อควรทราบ
นี่เป็น Front-end demo เท่านั้น ไม่มี backend, ไม่มีระบบบัญชีจริง, ไม่มี Payment Gateway, ไม่มีการตัดเงินจริง และไม่มีการส่งมอบเกมจริง อย่ากรอกข้อมูลบัตรหรือรหัสผ่านจริง
